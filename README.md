## 📌 О проекте и что нового в релизе `v2.0`

**MyProfile** — интерактивное консольное приложение на чистом Python (Standard Library), предназначенное для безопасного сбора, валидации, хранения и экспорта личных и банковских реквизитов индивидуального предпринимателя.

В версии **`v2.0` (Secure OOP Edition)** проект полностью переработан по принципам **безопасной разработки (Secure Coding / AppSec)** и выполнены все пункты изначального Roadmap `v1.0`:
1. **Переход на модульную ООП-архитектуру (`myprofile/models.py`):** данные разделены на датаклассы `PersonalInfo`, `EntrepreneurRequisites` и агрегат `EntrepreneurProfile`.
2. **Исправление уязвимости потери ведущих нулей (Data Corruption Fix):** в `v1.0` хранение БИК (например, `044525225`) и счетов в типе `int` приводило к отбрасыванию ведущего нуля (`44525225`). В `v2.0` реквизиты проходят строгую цифровую санитизацию и хранятся в неизменяемом строковом формате.
3. **Защита от отказов в обслуживании при вводе (`ValueError` DoS Prevention):** все точки пользовательского ввода обёрнуты в отказоустойчивый валидатор `prompt_validated` без падения программы при вводе нечисловых символов.
4. **Контроль целостности файла профиля (`SHA-256 File Integrity Monitoring`):** при сохранении профиля в `profile_data.json` вычисляется криптографический хеш `SHA-256` канонического JSON. При загрузке система проверяет контрольную сумму и блокирует чтение (`IntegrityError`), если файл был несанкционированно изменён на диске.
5. **Маскирование персональных данных и счетов (`PII Masking`):** добавлен режим безопасного отображения и экспорта реквизитов (`40802***********0001`, `+375******55`) для защиты чувствительных данных при демонстрации экрана или пересылке.

## 🖥️ Архитектура и структура меню

```text
ГЛАВНОЕ МЕНЮ (MyProfile v2.0)
├── 1 - Ввести или обновить информацию
│   ├── 1 - Личная информация (Имя, Возраст [0..120], Телефон, Email [Regex], Индекс, Адрес)
│   ├── 2 - Информация о предпринимателе (ОГРНИП [15], ИНН ИП [12], Р/с [20], Банк, БИК [9], К/с [20])
│   └── 0 - Назад
├── 2 - Вывести информацию
│   ├── 1 - Личная информация
│   ├── 2 - Вся информация (полная карточка)
│   ├── 3 - Вся информация (с маскированием ПДн и счетов)
│   └── 0 - Назад
├── 3 - Сохранить / загрузить профиль (JSON + проверка целостности SHA-256)
├── 4 - Экспортировать карточку в TXT (полный или маскированный режим)
└── 0 - Завершить работу
```

## 🚀 Установка и быстрый старт

Требования: **Python 3.9+**, внешние зависимости для работы приложения не требуются.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/Voobrazhenie21-lab/code-python-project.git
cd code-python-project

# 2. Запустить интерактивное меню
python main.py

# 3. Запустить автоматический демо-режим (показывает полную и маскированную карточку)
python main.py --demo
```

### Запуск модульных тестов (`pytest`):

```bash
pip install -e ".[dev]"
pytest -v
```
